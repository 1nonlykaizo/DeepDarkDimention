# Ancient City Portal

Unlock the mysteries hidden beneath the Deep Dark.

**Ancient City Portal** transforms the mysterious Ancient City structure into a fully functional portal leading to the **Dark Deep Dimension**.

## Features

* Ancient City Portal activation system
* Custom Dark Deep Dimension
* Survival-friendly progression
* Custom Portal Igniter
* Lightweight and optimized
* Supports modern Minecraft versions

## How It Works

1. Find an Ancient City.
2. Ensure the center of the portal frame is completely empty.
3. Craft the **Ancient Igniter**.
4. Right-click the center of the frame using the Ancient Igniter.
5. The portal will activate and grant access to the Dark Deep Dimension.

## Ancient Igniter Recipe

Craft the portal igniter using:

* 1× Heavy Core
* 1× Echo Shard
* 1× Flint & Steel

This special item is required to activate the Ancient City Portal.

## Requirements

* Minecraft 1.21.11+
* Paper / Purpur Server
* Java 21+

## Installation

1. Download the plugin JAR.
2. Place it in your server's `plugins` folder.
3. Restart the server.
4. Find an Ancient City and begin your adventure.
